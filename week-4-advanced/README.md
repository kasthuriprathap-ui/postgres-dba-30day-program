# Week 4 — Advanced Operations, Migration, and Capstone

**Goal:** turn the mechanical knowledge from Weeks 1–3 into production-grade practice. By day 30 you can operate a PostgreSQL fleet: replicate, fail over, harden, monitor, migrate from SQL Server, and drill DR.

| Day | Topic |
|---|---|
| 22 | Replication: streaming, logical, slots |
| 23 | High-availability patterns (Patroni, cloud-native) |
| 24 | Security hardening across clouds |
| 25 | Monitoring & observability |
| 26 | Migration from SQL Server: DMS, Babelfish, tooling |
| 27 | Extensions ecosystem |
| 28 | Cost optimization |
| 29 | DR drills |
| 30 | Capstone project |

There are two things that make this week different from the others:

1. **Every topic has a runbook.** Get in the habit of writing 10-line runbooks for every operation you do.
2. **Trade-offs, not answers.** By this point in the program, "it depends" is a legitimate answer — you must be able to defend both sides.
